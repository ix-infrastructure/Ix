## Install in one line

```bash
curl -fsSL https://ix-infra.com/install.sh | sh    # macOS / Linux
```

```powershell
irm https://ix-infra.com/install.ps1 | iex          # Windows (install Node.js 22+ and Docker Desktop first)
```

Then map a repository and ask it a question:

```bash
ix map .                      # build the graph for this repo
ix explain AuthService        # what is this, and what does it touch?
ix impact verify_token        # what breaks if I change this?
```

## What you can do with Ix

<CardGrid>
  <Card title="Answer structural questions" icon="magnifier">
    Find a symbol, see what calls it, follow a flow through the code, and measure the blast radius of a change.
    Each answer covers one symbol or flow instead of whole files.
  </Card>
  <Card title="Give your agents a map" icon="rocket">
    `ix mcp install` registers the graph tools with Claude Code, Codex, Cursor, VS Code, Gemini CLI, OpenClaw and
    opencode.
  </Card>
  <Card title="Keep context between sessions" icon="document">
    The graph lives on your machine and persists. Your architecture is mapped once, not rediscovered every session.
  </Card>
  <Card title="See the whole system" icon="puzzle">
    `ix view` opens Compass, an interactive visualizer of your codebase's structure.
  </Card>
</CardGrid>
