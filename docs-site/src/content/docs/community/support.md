| Where | For |
|---|---|
| [Discord](https://discord.gg/ncEYVHVqZ8) | Questions, help getting set up, and talking with the team and other users |
| [GitHub issues](https://github.com/ix-infrastructure/Ix/issues) | Bug reports and feature requests |
| [Security](/community/security/) | Reporting a vulnerability privately |

When you report a bug, include the output of `ix --version` and `ix doctor`, the command you ran, and what you
expected. Run the command again with `IX_DEBUG=1` to capture a full stack trace.
