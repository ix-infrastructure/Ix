Agents navigate the Ix graph instead of re-deriving your architecture from whatever fits in a prompt. There are three
ways to connect one, and you can combine them.

| Option | What it gives the agent | Best for |
|---|---|---|
| **MCP server** | Ix's graph tools as native MCP tools | Any MCP-capable client. Start here |
| **Agent skill** | Instructions for driving the `ix` CLI | Agents that run shell commands |
| **Native plugins** | A per-client package with hooks, such as re-ingesting files you edit | Deeper integration with one client |

## The fastest path

```bash
ix mcp install
```

This detects the AI clients on your machine (**Claude Code, Codex, Cursor, VS Code, Gemini CLI, OpenClaw and
opencode**) and registers Ix's MCP server with each one. Then ask your agent a question about your codebase.
